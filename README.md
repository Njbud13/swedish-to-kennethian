# Swedish → Kennethian Translator 🇸🇪➡️🤷‍♂️

This project translates **standard Swedish** into **Kennethian** –  
a dialect based on Swedish, enhanced with irony, over-explanation,
resignation, and mild passive-aggressive clarity.

Kennethian is commonly used when:
- Something *should* be obvious but isn’t
- You’re explaining things for the third time
- The situation is technically fine, but emotionally exhausting

## Example

Swedish:
> "Det är inga problem."

Kennethian:
> "Det är inga problem, vilket betyder att det absolut är ett problem men vi låtsas annat tills det exploderar."

## How it works

The translator uses:
- Phrase mappings
- Contextual irony expansion
- Optional exaggeration layer (because of course)

## Usage

```bash
python translator.py "Det löser sig"
```

Output:

Det löser sig, vilket betyder att ingen vet hur men vi hoppas på tur.
